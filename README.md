# Python Calculator

A simple command-line calculator written in Python.

## Features
- Addition (`+`), subtraction (`-`), multiplication (`*`) and division (`/`)
- Continue calculating with the previous result
- Start a fresh calculation at any time
- Screen clears between new calculations

## How to run
1. Install Python 3.
2. Download `calculator.py`.
3. Open a terminal in the same folder and run:

```
python calculator.py
```

## How to use
1. Enter the first number.
2. Pick an operation: `+`, `-`, `*` or `/`.
3. Enter the second number. The result is displayed.
4. Then choose:
   - `y` to continue calculating with the result
   - `n` to start a new calculation
   - any other key (e.g. `x`) to exit

## Example
```
enter the first number:4
pick an operation:+
enter the second number:6
4 + 6 = 10
```

## Limitations
- Only whole numbers are accepted.
- Dividing by zero or typing an invalid operation will crash the program.
